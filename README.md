# Sales Falcon — Official Website

> **Primary Tagline:** “WE POWER YOUR SALES TEAM.”

## 🛠 Tech Stack

- **Framework:** React 19 + Vite 8
- **Icons:** Lucide React
- **Styling:** Custom CSS Design System (no heavy UI frameworks, optimal Lighthouse scores)
- **Deployment:** Vercel

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deployment to Vercel

The project includes pre-configured `vercel.json` with security headers, clean URLs, and static asset caching.
Deploy directly via Vercel CLI:

```bash
vercel --prod
```
